Descripción detallada

HELMO · Firmware 2 de 2: módulo HMI de voz y gestos para el nodo de pH.

Autor
Esteban Eduardo Escarraga
Versión
1.0.0
Fecha
2026-11
  • Hardware: Arduino Nano 33 BLE Sense (Rev1 o Rev2), conectado por UART al nodo Heltec V3.
  • Entorno: Arduino IDE, placa "Arduino Nano 33 BLE" (paquete Arduino Mbed OS Nano Boards).
Funciones principales
  1. Voz: reconocimiento continuo con el modelo de Edge Impulse speech_recognition_Esteban (Amarillo, Rojo, Verde).
  2. Gestos: clasificador de movimiento con el IMU (punch, flex). Usa el TensorFlow Lite Micro incluido en la librería de Edge Impulse para no tener dos copias de TensorFlow.
  3. Envía al nodo cada detección confiable; el nodo decide la acción y si la reporta a TTN.
  4. Muestra el pH recibido como semáforo en el LED RGB y cada detección con su color durante 1,5 s.
Semáforo del LED RGB
verde = normal · amarillo = cerca del límite · rojo parpadeando = alarma sin reconocer · rojo fijo = alarma reconocida · azul parpadeando = OTA en curso · azul tenue = esperando al nodo.
Conexión (lógica de 3,3 V en ambas placas)
 Nano D1 (TX) -> Heltec GPIO 47 (RX)
 Nano D0 (RX) <- Heltec GPIO 48 (TX)
 GND          -- GND
Protocolo UART (texto, 115200 baud, una línea por mensaje)
 Nano -> Heltec:  HOLA,<ver> | PING | EVT,V,<etiqueta>,<conf%> | EVT,G,<etiqueta>,<conf%>
 Heltec -> Nano:  PH,<pH x100>,<estado>,<reconocida> | OTA,<1|0> | ACK,<etiqueta>
Precondición
Instalar el .zip de Edge Impulse y copiar el model.h de gestos con el array renombrado a modelo_gestos. Ajustar IMU_REV2 según la placa.
